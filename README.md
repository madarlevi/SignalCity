
# 📡 SignalCity

**A 2D radio signal and human behavior simulator built with C# and Raylib-cs.**

[![SignalCity Gameplay Demo](https://img.youtube.com/vi/TaFaNTNhG4k/maxresdefault.jpg)](https://www.youtube.com/watch?v=TaFaNTNhG4k)

Click the image above to watch the SignalCity gameplay demo!

## 🌍 About

SignalCity is an interactive 2D simulation where you can build your own environment, place radio towers, buildings, and people, and observe how signal coverage influences human behavior.

The goal is to explore how wireless networks, obstacles, and individual decisions affect the distribution of people in an environment.

## ✨ Features

- 📡 Place radio towers with adjustable signal strength.
- 🌈 Visualize signal coverage using a heatmap.
- 🏙️ Create a customizable 2D environment.
- 🧍 Simulate people searching for better internet connections.
- 🛠️ Interactive editor with a toolbar and property controls.

## 🧠 Planned Features

- Signal attenuation caused by buildings.
- Individual personalities, including laziness and internet demand.
- Social interactions and information sharing between people.
- Network congestion and bandwidth distribution.
- Simulation statistics and visualizations.

## 🛠️ Technologies

- **Language:** C#
- **Framework:** .NET

## 🚀 Getting Started

### Requirements

- .NET SDK
- Windows or Linux

### Installation

1. Clone the repository.
2. Open a terminal in the project folder.
3. Run the following commands:

    dotnet restore
    dotnet run

## 🎮 Controls

| Action | Control |
|---|---|

| Delete objects | Delete tool |

## 🔬 Scientific Background

SignalCity uses simplified mathematical models of radio signal propagation and agent-based simulation to demonstrate how wireless coverage and human behavior interact.

It is an educational simulation, not a professional radio network planning tool.
